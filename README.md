# Jarvis — этап 1–2 недели

Это текстовая версия помощника. На данном этапе здесь **нет распознавания речи,
синтеза голоса, ИИ и системы напоминаний** — они относятся к следующим этапам плана.

## Возможности

- приветствие;
- вывод текущих даты и времени;
- справка по командам;
- открытие сайтов в браузере;
- запуск приложений из белого списка;
- обработка неизвестных команд и типовых ошибок.

## Требования

- Python 3.10 или новее;
- интернет нужен только для открытия сайтов;
- сторонние библиотеки не требуются.

## Запуск

Открой терминал в папке проекта и выполни:

```bash
python main.py
```

На некоторых системах команда может называться `python3`:

```bash
python3 main.py
```

## Примеры команд

```text
привет
время
сайт wikipedia.org
открой сайт github.com
открой приложение калькулятор
помощь
выход
```

## Настройка приложений

Открой `config/apps.json`. Внутри есть отдельные списки для:

- `windows` — Windows;
- `darwin` — macOS;
- `linux` — Linux.

Добавляй приложение в список своей операционной системы. Значение должно быть
массивом аргументов запуска. Например, для Windows:

```json
"мой редактор": ["C:\\\\Program Files\\\\Editor\\\\editor.exe"]
```

Используется белый список: помощник запускает только явно добавленные приложения.
Не добавляй в него неизвестные команды или исполняемые файлы.

## Тесты

Из корневой папки проекта:

```bash
python -m unittest discover -s tests
```
